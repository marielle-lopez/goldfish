# Goldfish

## Changelog
- Created `cards.json` file to house data of all cards in a deck
- Displayed each card from `cards.json` on the homepage
- Installed Tailwind CSS for styling
- Created `CardComponent` to display the cards
- Display cards in a 6 by 9 grid
- Created and used `shuffle()` function to randomise the order of cards in a list
    - The algorithm of `shuffle()` is based on the Fischer-Yates (or Knuth) algorithm
